# trust.metaviews.ca

Commercial microsite for MetaViews AI trust, literacy, and adoption work in response to Canada's renewed federal AI strategy.

Primary domain: https://trust.metaviews.ca/

Source context:
- `trust.docx` — initial copy and positioning draft.
- `docs/opportunity-assessment.md` — commercial opportunity assessment.
- `docs/roadmap.md` — execution, deployment, and promotion roadmap.

## Intended site position

MetaViews helps Canadian organizations turn AI pressure into practical curiosity, trust, literacy, stakeholder buy-in, and adoption capacity — especially where open-source AI, agentic workflows, sovereignty, governance, cross-functional change, and communications intersect.

## Hosting plan

- GitHub repository for source control.
- Cloudflare Pages for static hosting.
- Custom subdomain: `trust.metaviews.ca`.

## Next build decision

Recommended first implementation: a static microsite with one strong landing page, service sections, contact CTA, SEO metadata, and deployment through Cloudflare Pages. Eleventy or Astro are both suitable; for speed and maintainability, use Eleventy unless the design direction calls for a richer component system.
